⚡ The Speed Challenge

How fast can you open Notepad?

Method 1 (The Long Way) Click Start → Scroll through apps → Find "Notepad" → Click it
⏱️ Time: About 10–15 seconds
Method 2 (The Fast Way) Press Windows key → Type "note" → Press Enter
⏱️ Time: About 3 seconds!
💬 Discussion: What if you could save time like that on EVERYTHING you do on the computer?

⚙️ Make Your Computer Work for YOU

Accessibility and display settings

🔍
Magnifier — Press Win + + to zoom in, Win + Esc to exit
📏
Text Size — Settings → Display → Scale: change to 125% or 150%
🖱️
Mouse Pointer — Settings → Accessibility → Make pointer larger and more visible
🌙
Night Light — Reduces blue light for comfortable evening use
✅ All these settings can be changed back anytime. Experiment!
