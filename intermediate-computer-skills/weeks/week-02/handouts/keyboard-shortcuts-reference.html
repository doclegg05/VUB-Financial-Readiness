Windows Keyboard Shortcuts — Quick Reference

KEEP AT YOUR DESK
VUB Intermediate Computer Skills — Week 2
⭐ Everyday Essentials (use these first!)
Ctrl + CCopy selected text or file
Ctrl + VPaste what you copied
Ctrl + XCut (copy + delete)
Ctrl + ZUndo last action
Ctrl + YRedo (undo the undo)
Ctrl + ASelect everything
Ctrl + SSave your work
Ctrl + PPrint
Ctrl + FFind / search on page
Windows Navigation
WinOpen Start menu
Alt + TabSwitch between windows
Alt + F4Close current window
Win + LLock your computer
Win + DShow desktop (minimize all)
Win + EOpen File Explorer
Win + IOpen Settings
Window Snapping
Win + ←Snap window to left half
Win + →Snap window to right half
Win + ↑Maximize window
Win + ↓Minimize / restore window
Screenshots
PrtScnCapture entire screen
Alt + PrtScnCapture active window only
Win + Shift + SSnip & Sketch (select area)
Accessibility
Win + +Turn on / zoom in Magnifier
Win + −Zoom out Magnifier
Win + EscTurn off Magnifier
Pro tip: The best way to learn shortcuts is to use ONE new shortcut every day until it becomes automatic!
