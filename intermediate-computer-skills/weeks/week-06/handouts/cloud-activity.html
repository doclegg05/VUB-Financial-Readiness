🎯 Goal: Set Up Your Google Drive

Today you'll organize your Google Drive with folders, upload a file, create a Google Doc, and practice sharing. Follow the steps below and check off each task as you complete it.

Part 1: Access Google Drive

  • Open your web browser Use Chrome, Firefox, or Edge
  • Go to drive.google.com Type this address in the address bar and press Enter
  • Sign in with your Gmail account Use the email and password you created in Week 3

Part 2: Create Folders

Create three folders to organize your Drive:

  • Create folder: "VA Documents" + New → New folder → Type "VA Documents" → Create
  • Create folder: "Personal" Same steps as above
  • Create folder: "Photos" Same steps as above

Part 3: Upload a File

  • Find a file on your computer Use the sample file your instructor provided, or any document
  • Upload the file to Google Drive + New → File upload → Select file → Open
  • Move the file into your "Personal" folder Drag the file onto the folder, or right-click → Move to

Part 4: Create a Google Doc

  • Create a new Google Doc + New → Google Docs
  • Name your document Click "Untitled document" at top and type "My Grocery List"
  • Type a simple grocery list Add 5-10 items you might buy at the store
  • Watch for "Saved to Drive" Notice at the top - your document saves automatically!

Part 5: Practice Sharing

  • Go back to Google Drive Click the Drive icon in top left, or go to drive.google.com
  • Star your Google Doc Right-click on "My Grocery List" → Add to Starred
  • Share your document with the instructor Right-click → Share → Enter instructor's email → Viewer → Send

🎉 Congratulations!

You've set up your Google Drive! You now have:

  • 3 organized folders
  • A file uploaded to the cloud
  • A Google Doc that saves automatically
  • Experience sharing files

Bonus: Try accessing drive.google.com from your phone!
