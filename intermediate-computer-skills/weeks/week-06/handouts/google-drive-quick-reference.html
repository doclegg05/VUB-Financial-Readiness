🌐 Accessing Google Drive

drive.google.com

Sign in with your Gmail email and password

📁 Drive Navigation

Left Sidebar

  • 📂 My Drive - Your main storage area
  • 👥 Shared with me - Files others shared
  • 🕐 Recent - Recently opened files
  • ⭐ Starred - Your favorites
  • 🗑️ Trash - Deleted files (30 days)

📋 Common Tasks

Upload a File

  1. Click + New (top left)
  2. Select File upload
  3. Browse and select file
  4. Click Open

Or: Drag file from your computer into Drive window

Create a Folder

  1. Click + New (top left)
  2. Select New folder
  3. Type folder name
  4. Click Create

Share a File

  1. Right-click on file
  2. Click Share
  3. Enter email OR click "Copy link"
  4. Set permissions, click Send

Create a Google Doc

  1. Click + New (top left)
  2. Select Google Docs
  3. Start typing (auto-saves!)
  4. Click title to rename

🔐 Sharing Permissions

👁️
Viewer

Can only LOOK at file

💬
Commenter

Can view + add comments

✏️
Editor

Can view + CHANGE file

To remove access: Share → Click person's name → Remove

💡 Google Docs Tips

Auto-Save

No Save button needed! Google Docs saves automatically every few seconds. Look for "Saved to Drive" at top.

Access Anywhere

Open docs.google.com from any computer or phone to see your documents.

💡 Remember: Your Gmail account = Your Google Drive account. Same login for both! Google Drive gives you 15 GB free. Star important files for quick access.
