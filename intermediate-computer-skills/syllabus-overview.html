Course Description

This 8-week course builds on basic computer skills to teach intermediate digital literacy for veterans. Students gain hands-on experience with VA online services, video conferencing, email productivity, Microsoft Office applications, cloud computing, and an introduction to AI tools.

Learning Outcomes

  • Navigate VA online portals (VA.gov, MyHealtheVet, eBenefits) for healthcare and benefits.
  • Join and participate in video calls using Zoom and VA Video Connect for telehealth.
  • Organize and manage email efficiently using Gmail labels, filters, and professional etiquette.
  • Create formatted documents in Microsoft Word using styles, tables, and templates.
  • Build spreadsheets in Microsoft Excel with formulas, charts, and data organization.
  • Store, share, and sync files using Google Drive cloud storage.
  • Use AI tools like ChatGPT for practical everyday tasks.

Assessment & Materials

Pre-test (Week 1) and Post-test (Week 8) measure growth using VUB's 20-question exam. Participation and weekly tasks factor into completion. Materials: computer, flash drive, handouts provided each week.
