# VUB Assessment Report Service Kit

Use this kit to build custom pre/post assessments that produce clean PDF-style reports for VUB records, instructors, coordinators, and grant auditors.

This is not a full app. It is a service workflow: you collect the test requirements, adapt the reusable HTML template, verify the report, and deliver a polished assessment package.

## What This Kit Produces

- A student-facing HTML assessment
- Automatic scoring
- Score by category
- Individual PDF-style report through the browser print dialog
- Optional pre/post growth comparison
- Instructor-ready setup notes
- A repeatable process for building future tests quickly

## Recommended Service Offer

Sell this as a custom reporting service, not as a software sale.

Suggested name:

**VUB Assessment Reporting Package**

Core deliverables:

- Pre-test assessment file
- Post-test assessment file
- Branded PDF report layout
- Category score breakdown
- Detailed answer report
- Instructor directions
- One revision round after instructor review

Optional add-ons:

- Question writing or editing
- Printable paper version
- Cohort summary spreadsheet
- Instructor training session
- Annual refresh/update package

## Files In This Kit

| File | Purpose |
| --- | --- |
| `service-offer.md` | Plain-English service positioning and scope |
| `client-intake.md` | Questions to ask before building a test |
| `build-brief-template.md` | One-page build brief for each new client/course |
| `vibe-code-prompt-pack.md` | Prompts to use with an AI coding assistant |
| `production-checklist.md` | Build, test, and delivery checklist |
| `question-bank-template.json` | Reusable question bank format |
| `assessment-template.html` | Single-file assessment/report template |

## Fast Workflow

1. Complete `client-intake.md` with the coordinator or instructor.
2. Fill out `build-brief-template.md`.
3. Draft or clean the questions in `question-bank-template.json`.
4. Clone `assessment-template.html` into the client/course folder.
5. Replace the `CONFIG` block in the HTML file.
6. Test the assessment, scoring, and print report.
7. Deliver the files with simple instructor directions.

## Best First MVP

Start with one paid pilot:

- One course
- 20 questions
- 4-6 categories
- Pre-test and post-test
- Individual PDF reports
- No central database
- No login system

This keeps the offer focused on the part the coordinator liked most: clean, professional evidence reports.
