# Week 1 — "Inside the Computer" Lesson Video — Narration Script

Audience: older U.S. military veterans, newer to computers. Format: **watched straight through;
the hands-on lab happens after.** Target 6–8 min, ~120–135 wpm, every term defined on first use.
Built to the same shape, depth, and warm tone as the approved `week2-video-script.md`.

Maps to the existing lab `courses/digital-literacy-1/weeks/week-01/handouts/meet-your-computer-lab.html`
(Ch.1 → Lab Part 1 · Ch.2 → Lab Part 2 · Ch.3 → Lab Part 3 · Ch.4 → Lab Part 4). The pre-test is
taken in class **before** this video, so the video itself stays on the teaching content.

Scene-kinds: `chapterCard` · `uiCallout` · `compare` · `steps` · `question`.
Assets the user supplies for this video: **2 photoreal hero images** (Scenes 1 & 25) + **1 real
screenshot** (Scene 5, ports on the back of a desktop/laptop). Everything else is built in code.

Theme: `WEEK_THEMES.week1` (steel-blue accent). The three `question` scenes reuse the real
Knowledge-Check questions from the lesson (presentation.html, Slide 13), each with the answer plus
one reassuring "why" line.

| **10** · Ch.2 | `compare` | Memory vs. Storage | "Those last two get mixed up the most, so let's be clear. Memory — RAM — is short-term, like your desk. It holds what's open right now, and it empties when you shut down; more RAM lets you run more at once. It's measured in gigabytes, like 8 or 16. Storage — the drive — is long-term, like a filing cabinet. It keeps your files when the power is off; more storage holds more files. It's measured in gigabytes or terabytes, and a terabyte is about a thousand gigabytes. Memory is the desk; storage is the cabinet." | Built 2-column compare: 🧠 Memory (RAM) vs 💾 Storage (the Drive), measured-in line each. |

| **13** · Ch.3 | `compare` | Two kinds of software | "Software comes in two kinds. System software is the operating system itself — it runs the whole computer, starts up when you turn it on, and manages the hardware for you. On the lab PCs, that's Windows. Application software — apps — are the programs you open to do a task: a web browser like Edge or Chrome, a word processor, a PDF reader, email, a calculator, a game. So: the system runs the computer, and the apps do your work." | Built 2-column compare: 🪟 System software (runs the computer) vs 📂 Applications (do your tasks). |
| **14** · Ch.3 | `compare` | Paid vs. Free — both are safe | "You'll also hear about two ways software is shared. Proprietary software is owned by one company; you buy it or pay a subscription, and the inner code is private — like Microsoft Office or Windows. Open-source software has public code that's free to use, usually free to download, and maintained by a community — like Firefox, LibreOffice, or VLC. Which is better? Neither — it depends on your needs. Both kinds can be excellent. What matters most is where you get it." | Built 2-column compare: 🔒 Proprietary (buy it) vs 🔓 Open Source (free, community). |
| **15** · Ch.3 | `steps` | Install safely — where matters most | "So here's how to install a program safely.
