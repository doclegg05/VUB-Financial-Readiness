# VUB Financial Readiness Course - 7-Week Curriculum

This folder organizes the course into a reusable seven-week teaching sequence. The current cohort calendar is listed in the course schedule handout.

## Class Sequence

| Week | Sequence | Class Plan |
|---|---|---|
| 1 | Week 1 | Pre-test + Module 1: Retirement Timelines & Preparation |
| 2 | Week 2 | Module 2: Disability Pay & Compensation |
| 3 | Week 3 | Module 3: Healthcare & Long-Term Care |
| 4 | Week 4 | Module 4: Managing Retirement Income and income-system interactions |
| 5 | Week 5 | No class - Memorial Day |
| 6 | Week 6 | Module 5: Legacy Planning |
| 7 | Week 7 | Review + post-test |

## Teaching Notes

- Use `index.html` at the project root as the live classroom course.
- The files in each weekly folder are copied from the master teaching folders so the original web app links keep working.
- Week 5 is reserved for Memorial Day with no class meeting.
- Week 7 should stay focused on review, questions, post-test completion, and next-step resources.
- Videos are not duplicated into these folders because they are large. Use `videos/output/` for the finished MP4s.
- Use `GOOGLE-DRIVE-COLLECTION.md` to prepare the assessment upload folders and student return workflow.
