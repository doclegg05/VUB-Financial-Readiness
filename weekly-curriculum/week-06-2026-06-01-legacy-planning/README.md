# Week 6 - Legacy Planning

## Focus

Module 5: Legacy Planning

## Class Flow

1. Teach Module 5 from `financial-readiness.html#module5`.
2. Use the SBP decision worksheet for the main applied activity.
3. Use the Survivor Income Map to connect SBP, DIC, Social Security, life insurance, and retirement-account inheritance.
4. Use the End-of-Life Readiness Checklist to stress care wishes, legal authority, document location, and first-week survivor steps.
5. Use the practical scenarios for discussion and instructor answer guidance.
6. Reserve the final minutes to preview the Week 7 review and post-test.
