Describe itThe name should say what's inside
Add a dateUse YEAR-MONTH (2026-06) so files sort in order
Use hyphensHyphens or underscores instead of spaces
Use foldersGroup related files (e.g. a "VA Documents" folder)
Save oftenCtrl+S — and back up (3-2-1: 3 copies, 2 places, 1 away)

🖨 Print Settings

Open printCtrl+P
PortraitTall page — letters (the usual choice)
LandscapeWide page — tables, photos
Double-sided"Print on Both Sides" — saves paper
CopiesHow many to print
Pages"All" or a range like 1-3
PreviewAlways check it before you print!
No paper?Pick "Microsoft Print to PDF" to make a file

✉ Email Response Options

ReplyAnswers the sender only (use this most)
Reply AllAnswers everyone on the message — only when all truly need it
ForwardSends the message to someone new
BccSends a copy privately — others can't see that address

👍 Email Etiquette

  • Clear subject line
  • Greeting + your name; get to the point
  • Re-read before you send
  • ALL CAPS (reads like shouting)
  • Sending in anger — wait, then reply calmly
Before you hit Send: Check the "To" line. Is this a Reply or a Reply All? It's the easiest mistake to make — and to avoid.
