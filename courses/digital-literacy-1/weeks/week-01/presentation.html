Input & Output Devices

How you talk to the computer, and how it talks back

⌨️ Input Devices (you → computer)

  • Keyboard — type text and commands
  • Mouse / touchpad — point and click
  • Microphone — record your voice
  • Webcam — capture video
  • Scanner — turn paper into a file

🖥️ Output Devices (computer → you)

  • Monitor / screen — shows the picture
  • Speakers / headphones — play sound
  • Printer — puts your work on paper
An easy way to remember
Input goes in to the computer. Output comes out to you. A touchscreen does both — it takes your touch (input) and shows the picture (output).

Ports, Cables & Connectors

The plugs on the back and sides of your computer

🔵
USB The most common plug. Connects a keyboard, mouse, flash drive, or phone charger. USB-A is the flat rectangle; USB-C is the small oval that fits either way up.
📺
HDMI Carries picture and sound to a monitor or TV with one cable.
🌐
Ethernet A wider plug (looks like a fat phone jack) for a wired internet connection.
🔋
Power Connects the computer or laptop charger to the wall.
Good news
Plugs are shaped so they only fit the right port. If a cable will not go in, turn it over or try a different port — never force it.

Types of Computing Devices

Same idea, different sizes

🖥️
Desktop Stays on a desk. Powerful, easy to repair, plugs into the wall. The tower, monitor, keyboard, and mouse are separate pieces.
💻
Laptop Folds shut and runs on a battery. Screen, keyboard, and touchpad are built in. Portable.
📱
Tablet A flat touchscreen, like a big phone. Lightweight, good for reading and video.
📞
Smartphone A pocket computer that also makes calls. Always with you and connects over cellular.
The big idea
All four are computers. They take input, do work, store information, and show output — just in different sizes for different jobs.

Inside the Box

The main parts that do the work

⚙️
CPU — the "brain" The processor that does the thinking and runs your programs.
🧠
RAM — short-term memory The computer's "desk space." Holds whatever you are working on right now.
💾
Drive — long-term storage The "filing cabinet." Keeps your files, photos, and programs even when the power is off.
You do not have to memorize this
Knowing these names just helps you understand store clerks, repair techs, and the numbers you will see in the next slide.

Memory vs. Storage

Two different things people often mix up

🧠 Memory (RAM)

  • Short-term, like your desk
  • Holds what is open right now
  • Empties when you shut down
  • More RAM = run more at once
  • Measured in GB (e.g. 8 or 16 GB)

💾 Storage (the Drive)

  • Long-term, like a filing cabinet
  • Keeps files when power is off
  • Holds photos, documents, programs
  • More storage = keep more files
  • Measured in GB or TB (e.g. 256 GB, 1 TB)
Remember it this way
Memory is your desk — clears off at the end of the day. Storage is your filing cabinet — keeps things for good. A TB (terabyte) is about 1,000 GB.

What Is Software?

Hardware is what you touch; software is what it runs

🪟 System Software

  • The operating system itself (Windows)
  • Runs the whole computer
  • Starts up when you turn it on
  • Manages the hardware for you

📂 Application Software ("apps")

  • Programs you open to do a task
  • Web browser (Edge, Chrome)
  • Word, a PDF reader, a photo viewer
  • Email, games, a calculator
A simple way to picture it
Hardware = the parts you can hold. System software = the operating system that runs everything. Applications = the individual programs you open to write, browse, or watch.

Paid vs. Free Software

Proprietary and open-source — both are normal and safe

🔒 Proprietary

  • Owned by one company
  • You buy it or pay a subscription
  • The inner code is private
  • Examples: Microsoft Office, Windows

🔓 Open Source

  • Code is public and free to use
  • Usually free to download
  • Maintained by a community
  • Examples: Firefox, LibreOffice, VLC
Which is better?
Neither — it depends on your needs. Both kinds can be excellent. The important thing is to download from a trusted place, which is next.

Installing Software Safely

Where you get a program matters most

  1. Use a trusted source
    The Microsoft Store, or the maker's official website (for example, microsoft.com or mozilla.org).
  2. Check the web address
    Make sure it is the real company's site, not a look-alike with a slightly wrong name.
  3. Run the installer and read each screen
    Click Next carefully. Decline any extra "bonus" toolbars or programs you did not ask for.
  4. Approve the security prompt
    Windows asks "Do you want to allow this app to make changes?" Click Yes only if you trust the source.
⚠️ Stay safe
Never install software from a pop-up ad or an email link. "Your computer is infected — click here!" is always a scam. When in doubt, ask the instructor.

What Is an Operating System?

The master program that runs the whole computer

🪟

The Operating System (OS)

The OS starts when you power on and stays running the whole time. It shows your desktop, manages your files, and lets every app share the keyboard, screen, and memory. The computers in this lab run Microsoft Windows.

🖱️
What the OS gives you The desktop, the taskbar, the Start menu, windows, and File Explorer.

Windows, Mac & Mobile

The operating systems you will meet most

🪟
Windows (Microsoft) The most common OS on desktops and laptops — and what this lab uses. Look for the Start button in the bottom-left corner.
🍎
macOS (Apple) Runs only on Apple Mac computers. Same idea as Windows, with a slightly different look.
📱
Mobile: Android & iOS The operating systems on phones and tablets. Android (Google) runs on many brands; iOS / iPadOS (Apple) runs on iPhones and iPads. They use taps and swipes instead of a mouse.
The reassuring part
Once you learn one operating system, the others feel familiar. They all let you open programs, save files, and connect to the internet.

Knowledge Check

Read each question, think about your answer, then reveal it

1. Which of these is an input device?

A printer · A monitor · A keyboard · A speaker

Answer: A keyboard. You use it to put information into the computer. A printer, monitor, and speaker are all output devices.

2. What is the difference between memory (RAM) and storage (the drive)?

Answer: RAM is short-term — like your desk — and empties when you shut down. Storage is long-term — like a filing cabinet — and keeps your files when the power is off.

3. Where is the safest place to download a new program?

Answer: From a trusted source — the Microsoft Store or the maker's official website. Never from a pop-up ad or an email link.
