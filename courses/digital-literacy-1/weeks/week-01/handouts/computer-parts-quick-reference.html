⭐ Memory vs. Storage (the most important difference!)
Memory (RAM)Short-term, like your desk. Holds what is open right now. Empties when you shut down. Measured in GB.
Storage (the Drive)Long-term, like a filing cabinet. Keeps files, photos, and programs even when off. Measured in GB or TB.
Input Devices (you → computer)
KeyboardType text and commands
Mouse / TouchpadPoint and click
MicrophoneRecord your voice
WebcamCapture video
ScannerTurn paper into a file
Output Devices (computer → you)
Monitor / ScreenShows the picture
Speakers / HeadphonesPlay sound
PrinterPuts work on paper

Software & Operating Systems
System softwareThe OS that runs everything (Windows)
Application ("app")A program you open: browser, Word
ProprietaryPaid, code is private (MS Office)
Open sourceFree, code is public (Firefox, VLC)
Operating systemsWindows, macOS, Android, iOS
Install safely: only download programs from the Microsoft Store or the maker's official website — never from a pop-up ad or an email link.
