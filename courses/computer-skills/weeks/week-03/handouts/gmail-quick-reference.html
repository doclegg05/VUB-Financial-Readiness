📋 Common Tasks

Create a Label

  1. Scroll down left sidebar, click More
  2. Click Create new label
  3. Type label name, click Create

Apply a Label

  1. Open email or check the checkbox
  2. Click label icon (tag) in toolbar
  3. Check labels to apply, click Apply

Create Signature

  1. Click gear icon > See all settings
  2. Scroll to Signature section
  3. Click Create new, type signature
  4. Scroll down, click Save Changes

Add Attachment

  1. Click Compose for new email
  2. Click paperclip icon at bottom
  3. Browse, select file, wait for upload
  4. Or drag file directly into compose window

🔍 Search Operators

Find by Person

  • from:va.gov - From VA
  • to:john@email.com - Sent to John

Find by Content

  • subject:appointment - In subject
  • has:attachment - Has files

Find by Date

  • after:2025/01/01 - After date
  • before:2025/06/01 - Before date

Find by Status

  • is:unread - Unread only
  • is:starred - Starred only

📬 CC vs BCC

CC (Carbon Copy)

  • All recipients can see CC'd people
  • Use to keep others "in the loop"
  • Example: CC your supervisor

BCC (Blind Carbon Copy)

  • BCC recipients are hidden
  • Use for large groups (protects privacy)
  • Prevents Reply All chaos
💡 Remember: Archive instead of Delete when in doubt! Archived emails are hidden but still searchable. Click All Mail in the sidebar to see everything. Attachment limit is 25 MB.
