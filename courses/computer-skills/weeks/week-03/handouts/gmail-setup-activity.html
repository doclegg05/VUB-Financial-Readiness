📧 Gmail Setup Activity

VUB Intermediate Computer Skills - Week 3

ACTIVITY

🎯 Today's Goal

Set up your Gmail account for maximum productivity! Complete each task below and check it off when done. This will take approximately 20 minutes.

Part 1: Create Labels

  • Create a "VA" label Left sidebar → More → Create new label → Type "VA" → Create
  • Create a "Financial" label Same steps as above
  • Create a "Personal" label Same steps as above
  • Color-code your labels Hover over label → Click 3 dots → Label color → Choose colors

Part 2: Create Your Signature

  • Open Settings Click gear icon (⚙️) → See all settings
  • Find the Signature section Scroll down to "Signature" section
  • Create new signature Click "Create new" → Name it "Main" → Type your signature
  • Save changes Scroll to bottom → Click "Save Changes"

Draft your signature here first:

Example: Best regards,
John Smith
US Army Veteran
(304) 555-0123

Part 3: Compose a Test Email

Send a test email to yourself using what you've learned!

  • Click Compose Red "Compose" button in top left
  • Address it to yourself Put YOUR email address in the "To" field
  • Write a professional email Use proper greeting, clear purpose, professional closing
  • Send it! Click the blue Send button
  • Apply a label to your received email Open received email → Click label icon → Select "Personal"

Bonus Challenges (If Time Permits)

  • Enable keyboard shortcuts Settings → See all settings → Keyboard shortcuts → ON → Save
  • Add a contact Google Apps (9 dots) → Contacts → Create contact
  • Star an important email Click the star icon next to any email

🎉 Great Work!

You've set up Gmail for success! You now have organized labels, a professional signature, and you've practiced composing a proper email. Keep using these skills every time you check your email!
