📄 Word Document Activity

VUB Intermediate Computer Skills - Week 4

ACTIVITY

🎯 Today's Goal

Create a professional contact list document using styles, tables, headers, and page numbers. Follow the steps below and check each task as you complete it. Time: 20 minutes.

📋 Your Final Document Should Look Like This:

Your Name | Today's Date
My Important Contacts
Family
Name Phone Number Relationship
Jane Smith (304) 555-1234 Wife
John Smith Jr. (304) 555-5678 Son
Mary Johnson (304) 555-9012 Sister
Page 1

Part 1: Set Up Your Document

  • Open Microsoft Word Start menu → Microsoft Word, or click Word icon
  • Create a new blank document File → New → Blank document
  • Save your document immediately Ctrl+S → Name it "Contacts_YourName" → Save to Documents

Part 2: Add Title and Heading with Styles

  • Type the title: "My Important Contacts" Just type the text, don't worry about formatting yet
  • Apply the Title style Select the title text → Home tab → Click "Title" in Styles group
  • Press Enter and type: "Family" This will be your first section heading
  • Apply Heading 1 style to "Family" Select "Family" → Home tab → Click "Heading 1" in Styles

Part 3: Create Your Table

  • Click below your "Family" heading Press Enter to create a new line
  • Insert a table: 3 columns x 4 rows Insert tab → Table → Drag to select 3x4 grid → Click
  • Fill in the header row Type: Name | Phone Number | Relationship (use Tab to move between cells)
  • Fill in at least 3 contacts Can be real or made up - your choice!
  • Apply a Table Style Click in table → Table Design tab → Choose a style you like

Part 4: Add Header and Page Number

  • Add a header Insert tab → Header → Choose "Blank" or a simple design
  • Type your name and today's date in the header Example: John Smith | Today's Date
  • Close the header Click "Close Header and Footer" button, or double-click in document body
  • Add page numbers Insert tab → Page Number → Bottom of Page → Plain Number 2 (centered)

Part 5: Final Steps

  • Run Spell Check Press F7 or Review tab → Spelling & Grammar
  • Save your document Ctrl+S to save
  • Show your instructor! Raise your hand when you're done

🎉 Bonus Challenges (If You Finish Early)

  • Add another section called "Medical Contacts" with Heading 1 style and a new table
  • Change the color scheme of your table
  • Try the Navigation Pane (View → Navigation Pane) to see your headings
