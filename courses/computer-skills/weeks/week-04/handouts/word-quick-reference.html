📋 Common Tasks

Insert Table

  1. Click where you want the table
  2. Insert tab → Table
  3. Drag to select rows/columns
  4. Click to insert

Add Header/Footer

  1. Insert tab → Header or Footer
  2. Choose a design or "Edit"
  3. Type your content
  4. Click "Close Header and Footer"

Add Page Numbers

  1. Insert tab → Page Number
  2. Choose position (Top/Bottom)
  3. Select a style
  4. Numbers update automatically

Use Templates

  1. File → New
  2. Search or browse templates
  3. Click to preview
  4. Click Create

📊 Table Formatting

Table Design Tab

  • Table Styles (colors/borders)
  • Header Row option
  • Banded Rows (alternating)

Layout Tab

  • Insert/Delete rows & columns
  • Merge cells
  • Align text in cells

📍 Ribbon Tab Guide

  • Home: Font, Paragraph, Styles
  • Insert: Tables, Pictures, Headers
  • Design: Document themes
  • Layout: Margins, Orientation
  • Review: Spell check, Comments
  • View: Zoom, Navigation Pane
💡 Pro Tips: Double-click at top/bottom of page to quickly edit header/footer. Use View → Navigation Pane to see all headings and jump between sections. Press F7 for spell check before saving!
