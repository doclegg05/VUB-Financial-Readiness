ChatGPT Practice Activity

ACTIVITY

Goal: Practice Using ChatGPT

In this activity, you'll practice writing prompts and using ChatGPT for different tasks. Complete each exercise and check off the box when done. Take your time!

Exercise 1: Your First Conversation

1
Start Simple
Task: Log into ChatGPT and ask a simple question: "What is the capital of West Virginia?"
I logged into ChatGPT successfully
I typed the question and received an answer

Exercise 2: Writing Help

2
Write an Email
Task: Ask ChatGPT to help you write an email. Choose ONE of these options:
  • An email to reschedule a doctor's appointment
  • A thank you email to a friend
  • An email asking about a product return
I typed my prompt and ChatGPT wrote an email for me
Tip: If the email is too long, type: "Make it shorter." If it's too formal, type: "Make it more casual."

Exercise 3: Explain Something

3
Get an Explanation
Task: Ask ChatGPT to explain something you've wondered about. Examples:
  • "Explain how WiFi works in simple terms"
  • "What's the difference between a debit card and a credit card?"
  • "Explain what streaming TV services are"
I received a helpful explanation

Exercise 4: Make a List

4
Create a Helpful List
Task: Ask ChatGPT to create a list for you. Choose ONE:
  • A packing list for a weekend trip
  • A grocery list for healthy meals
  • A checklist for preparing your home for winter
  • Gift ideas for a family member
ChatGPT created a useful list for me

Exercise 5: Improve a Prompt

5
Make It Better
Task: This prompt is weak: "Write something about cooking."

Rewrite it to be a STRONG prompt with specific details, context, and format.
I tested my improved prompt in ChatGPT

Reflection Questions
