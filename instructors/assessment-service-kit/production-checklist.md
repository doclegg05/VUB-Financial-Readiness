# Production Checklist

Use this checklist every time you create a paid assessment package.

## 1. Scope

- [ ] Client intake completed
- [ ] Build brief completed
- [ ] Number of tests confirmed
- [ ] Number of questions confirmed
- [ ] Categories confirmed
- [ ] Required report fields confirmed
- [ ] Branding confirmed
- [ ] Deadline confirmed

## 2. Question Bank

- [ ] Questions match course objectives
- [ ] Categories are consistent across pre-test and post-test
- [ ] Each question has 4 answer choices
- [ ] Each question has exactly one correct answer
- [ ] Answer key reviewed
- [ ] Plain language reviewed
- [ ] Sensitive data avoided
- [ ] Client/instructor approved content

## 3. HTML Build

- [ ] `CONFIG` values updated
- [ ] Question bank inserted
- [ ] Pre-test `assessmentType` set to `pre`
- [ ] Post-test `assessmentType` set to `post`
- [ ] Same `storageKey` used for matching pre/post pair
- [ ] Report footer customized
- [ ] No external dependencies added
- [ ] File names use lowercase hyphenated names

## 4. Functional Test

- [ ] Test opens in Chrome
- [ ] Test opens in Edge
- [ ] Test opens in Firefox, if available
- [ ] Start form works
- [ ] All questions render
- [ ] Mouse answer selection works
- [ ] Keyboard navigation works
- [ ] Submit requires all questions answered
- [ ] Overall score is correct
- [ ] Category scores are correct
- [ ] Pre-test saves result locally
- [ ] Post-test finds matching pre-test result
- [ ] Post-test still works without pre-test result

## 5. Print/PDF Test

- [ ] Print button opens print dialog
- [ ] Report header is correct
- [ ] Student fields are correct
- [ ] Score summary is correct
- [ ] Category breakdown is correct
- [ ] Detailed answer table is readable
- [ ] Post-test comparison is correct
- [ ] Report fits letter paper cleanly
- [ ] Colors print acceptably
- [ ] PDF file name guidance included for instructor

## 6. Delivery

- [ ] Files placed in a clean delivery folder
- [ ] Instructor directions included
- [ ] Coordinator summary included
- [ ] Client review copy sent
- [ ] Feedback applied
- [ ] Final files delivered
- [ ] Invoice sent
- [ ] Reusable improvements copied back into this kit
