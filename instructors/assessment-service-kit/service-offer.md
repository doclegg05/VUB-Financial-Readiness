# Service Offer: VUB Assessment Reporting Package

## Plain-English Positioning

I build custom pre/post assessment packages for VUB instructors that create clean, professional PDF-style reports for program records and grant documentation.

The goal is to make testing consistent across instructors while giving coordinators a polished report they can retain for audits, student progress evidence, and program improvement.

## What The Client Gets

### Standard Package

- One pre-test
- One post-test
- Branded assessment screens
- Automatic score calculation
- Score by learning category
- Printable individual report
- Pre/post improvement comparison on the post-test report
- Instructor usage guide
- One revision round

### Best For

- VUB course assessments
- Instructor-created workshops
- Grant reporting evidence
- Pre/post learning measurement
- Programs that need professional documentation without a full LMS

## What This Is Not

- Not a learning management system
- Not a central student database
- Not a Google Forms workflow
- Not a subscription app unless we decide to productize later

## Ownership Language

Use this position when discussing purchase:

"I can build and license the reporting package for your program. You own the course-specific questions and reports we create for your instructors. I retain the reusable template and production process so I can maintain it, improve it, and adapt it for future VUB needs."

## Discovery Questions

- How many instructors need this?
- How many different courses or workshops need tests?
- Do all instructors need the same format?
- Do reports need student names, anonymous IDs, or both?
- Do reports need instructor name, site, cohort, and date?
- Do auditors need individual reports, cohort summaries, or both?
- How many questions should each test include?
- Should the post-test use the same questions, parallel questions, or mixed review questions?
- Who approves the final answer key?
- How often will the tests be updated?
